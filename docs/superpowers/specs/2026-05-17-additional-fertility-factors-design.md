# 추가 출산율 요인 확장 분석 설계

작성일: 2026-05-17  
브랜치: `research/additional-fertility-factors`

## 배경

과제 안내문에는 9개 요인이 제시되어 있고, 현재 노트북은 개인소득을 포함해 강의자료 방식의 complete-case와 보간 비교 분석을 수행한다. 교수님 답변상 추가 변수 고려가 가능하므로, 기존 결과를 대체하지 않는 확장 분석을 설계한다.

## 목표

추가 변수는 "왜 출산율과 인구증감률이 지역별로 다르게 움직이는가"를 설명하는 보조 근거로 사용한다. 메인 결과는 기존 과제 기준 변수로 유지하고, 확장 변수는 발표에서 한 장 정도로 요약할 수 있게 한다.

## 권장 변수 세트

균형형 확장 세트를 기본으로 한다.

| 변수군 | 대표 지표 | 역할 |
| --- | --- | --- |
| 결혼 형성 | 조혼인율, 혼인건수, 평균 초혼연령 | 한국에서 출산율 변동이 혼인 변동을 통해 나타나는 경로 확인 |
| 교육비 부담 | 지역별 학생 1인당 월평균 사교육비 | 자녀 양육비 기대 부담 대리변수 |
| 주거비 부담 | 주택 매매가격지수, 전세가격지수 | 주거안정률로 포착되지 않는 가격 압력 보강 |
| 일-가정 양립 | 경력단절여성인구, 여성 고용률, 육아휴직 지표 | 출산 이후 경력 비용과 돌봄 부담 보강 |
| 청년 이동 | 청년순이동률, 청년 순이동자수 | 지역별 청년 유출입과 인구증감률 보조 설명 |

## 분석 설계

1. 추가 KOSIS 엑셀을 `data/` 하위에 원본 그대로 저장한다.
2. `01 데이터 인벤토리`에 출처, 기간, 단위, 최신 연도, 지역 단위를 추가한다.
3. `03 요인별 추출` 뒤에 `03-1 추가 요인 추출` 섹션을 둔다.
4. `04 강의자료 기준 분석`은 기존 변수를 메인으로 유지한다.
5. `05 보간 적용 분석`도 기존 변수 기준으로 유지하되, 확장 변수 세트는 별도 패널을 만든다.
6. `06 결과 비교` 뒤에 `06-1 확장 변수 민감도 비교`를 추가한다.
7. 결론에는 "기존 변수 기준 결과"와 "추가 변수 포함 시 달라지는 점"을 분리해서 한 문단으로 요약한다.

## 품질 기준

- 추가 변수별 결측률, 최신 연도, 공통연도 수를 먼저 출력한다.
- 시도-연도 패널이 되지 않는 변수는 PCA/PCR에 넣지 않는다.
- 공통연도가 3년 미만이면 통합 분석에는 넣지 않고 최신 그래프와 산점도만 만든다.
- 지역별 가격지수는 지역 간 절대 수준 비교가 아니라 시간 변화와 지역별 추이를 중심으로 해석한다.
- 보간된 값은 기존 방침대로 `is_imputed=True` 플래그를 유지한다.

## 예상 산출물

- 추가 변수 후보 표
- 추가 변수 데이터 인벤토리
- 기존 모델과 확장 모델의 표본 수 비교
- complete-case 확장 PCA/PCR
- 보간 확장 PCA/PCR
- 변수 순위 변화표: `base_rank`, `extended_rank`, `rank_change`

## 사용자 검토 필요 사항

노트북에 실제로 반영하기 전, 우선 아래 중 하나를 선택한다.

1. 보수형: 혼인, 사교육비, 주택가격만 추가
2. 균형형: 혼인, 사교육비, 주택가격, 경력단절, 청년순이동 추가
3. 탐색형: 균형형에 1인가구비율, 의료 접근성까지 추가
